## 2. Аудит: неоднозначності та рішення

Повна таблиця — у `progress.md` (розділ «Рішення»). Ключові:

1. **Залог при зростанні автоставки**: залог = max(10% від поточного максимуму, 50 ₴), утримується по парі (user, lot). Підвищення максимуму утримує лише різницю; зниження максимуму заборонено.
2. **Перебиття автоставкою**: ставка-максимум A перебита автоставкою B, що вища → залог A звільняється в тій самій транзакції; B утримує залог за свій максимум.
3. **Комісія**: `fee = max(1000, floor(price*5/100))` у копійках (цілочисельна арифметика). «Округлення на користь продавця» = комісія округлюється **вниз**; мінімум 10 ₴ (1000 коп.); fee ніколи не перевищує price.
4. **Другий шанс**: залог переможця, що не сплатив, іде продавцю. Другому учаснику пропонується ціна = його максимальна ставка; для нього резервується залог (10% від ціни, мін 50 ₴) на час пропозиції. Одна активна пропозиція на лот (partial unique index).
5. **Гонка продовження та закриття**: задача закриття перечитує `ends_at` під `FOR UPDATE`; якщо `ends_at > now` — нічого не робить. Закриття — CAS по статусу `active`.
6. **Ідемпотентність**: ключ унікальний у (user, scope). Інше тіло → 422 `IDEMPOTENCY_KEY_REUSED`. Паралельний повтор чекає на row-lock запису ключа.
7. **Маскування імен**: `першаЛітера***останняЛітера` у історії; для власних ставок — повне ім'я.
8. **Підміна часу**: `Clock` інжектується; у тестах `FakeClock`; BullMQ-затримки обчислюються з `clock`, а sweeper рахує в SQL з параметром `now` від Clock (не `now()` БД).
9. **Рівні максимуми**: лідирує раніший (за `created_at`, потім `id`).
10. **Купити зараз / ставка**: обидва беруть `FOR UPDATE` лота; хто перший — той виграв; інший отримує 409.
11. **Резервна ціна не досягнута** → `ended_unsold`, залоги звільняються.
12. **Автоставка власника**: заборонена (403 `OWN_LOT`).
13. **Валюта**: єдина UAH, копійки `bigint`.

## 3. Ризики

| Ризик | Міра |
| --- | --- |
| 50 паралельних ставок | `SELECT … FOR UPDATE` на лот, коротка транзакція, `seq` на лот; тест із 50 Promise.all |
| Сид 50k/500k | batched `INSERT`/COPY, відкладені індекси, прогрів статистики (`ANALYZE`) |
| Пошук/історія < 200 мс | Meilisearch + індекс `bids(lot_id, seq desc)` + keyset-пагінація |
| Звіт 90 днів < 500 мс | індекс по `ledger_entries(created_at)` + щоденний rollup `daily_turnover` |
| Хаос-вебхуки | дедуп за `provider_event_id`, state machine, unique на credit, reconciler щохвилини |
| Кілька worker | детерміновані `jobId`, `FOR UPDATE SKIP LOCKED`, CAS-статуси, unique на ефекти (листи/проводки) |
| Втрата Redis | Postgres — джерело правди; sweeper щосекунди по БД; BullMQ — лише прискорювач |
| Витік резервної ціни | явні DTO-мапери + тест, що скани payload-ів на заборонені поля |
